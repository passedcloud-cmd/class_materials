8차 - 과제 - 사용자 정보 클래스 예외 처리 Lv4

input()은 사용자가 그냥 엔터만 쳐도 빈 문자열("")을 반환할 뿐, TypeError를 발생시키지 않습니다.
"이름이 없거나 공백이면"이라는 조건은 예외 처리가 아니라 직접 검사해야 합니다.

if not self.name.strip():
    return None

→ self.name.의 앞뒤 공백을 제거. 
만약 입력값이 공백이거나 스페이스바만 눌렀다면 빈 문자열 ""가 되어 False
이걸 not으로 뒤집으면 True.



input()으로 받은 값은 항상 문자열이라 ValueError가 절대 발생하지 않습니다. 숫자인지 검사하려면 int(self.age)처럼 변환을 시도해야 예외가 발생할 수 있어요.
ValueError를 "처리"하려면 try-except로 변환해야 함

try:
    age_int = int(self.age)
except ValueError:
    print('나이는 숫자로 입력해야 합니다.')
    return False




파이썬에서 딕셔너리에 없는 키를 []로 조회하면 KeyError가 발생합니다.
self.user_data가 비어있는 딕셔너리({})인지 아닌지로 판단하는 게 더 정확합니다.


print(f"사용자 정보: \n이름: {self.user_data['이름']}\n나이: {self.user_data['나이']}")
큰따옴표와 작은 따옴표 따로 사용할 것.
