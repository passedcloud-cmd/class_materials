선형 회귀

잔차제곱합(RSS, Residual Sum of Squares)
Std.Error(표준오차): 표본을 뽑을 때마다 흔들리는 값. 작으면 좋음 
t-statistic: 계수 추정치가 0(=효과 없음)으로부터 표준오차 몇 배만큼 떨어져 있는가. 높을 수록 우연이 아니다. 좋음. 
p-value: 작을수록 유의함 
유의성 검정 - 결정계수 R^2 = 1 - RSS/TSS

다중선형 회귀: 독립변수 여러 개 
RSS 최소화로 계수를 추정함

로짓변환: 오즈에 log를 취함

LSM대신 MLE 사용 
우도(likelihood): 현재 확률 함수가 데이터를 얼마나 잘 설명하는지 나타낸 지표
우도 최대화 (MLE, maximum likelihood estimation)
이 확률(L(β))이 클수록 "이 β가 데이터를 잘 설명한다"는 뜻이니, 이걸 최대화하는 β(절편과 기울기)를 찾는 거예요. 1에 가까울수록 좋음.
log-likelihood

역전파: 순전파의 역순으로, 순전파를 통해 나온 오차를 활용하여 모델의 각 층의 가중치와 편향을 최적화 하는 것

단층 퍼셉트론 (Single-layer Perceptron)
입력 → 계산 → 출력, 한 단계로 끝나는 구조. 중간에 숨겨진 레이어(hidden layer)가 없어요.
입력 → [W, b 계산 + 판단] → 선형 출력

다층 퍼셉트론
레이어를 여러 개 쌓은 것이에요. 입력과 출력 사이에 숨겨진 레이어(hidden layer)가 하나 이상 껴 있어요.
입력 → [레이어1](ReLU) → [레이어2](ReLU) → [레이어3](ReLU) → 비선형 출력

퍼셉트론: 여러 개의 입력값을 받아 각각의 가중치를 곱하고 편향을 더한 뒤, 그 값이 임계치를 넘으면 1, 넘지 않으면 0(또는 -1)을 출력하는 단순한 이진 분류기
입력, 가중치, 가중합, 활성화 함수

Flatten
활성화 함수 : 시그모이드 함수를 사용하다가 현재는 ReLU 사용
MLP 학습 과정: 1 순전파, 2 손실 함수 계산(평균제곱오차/교차 엔트로피), 3 역전파, 4 옵티마이저(w, b를 수정) -> 반복 
기울기(gradient) = (W를 살짝 바꿨을 때 Loss가 변하는 정도) / (W가 바뀐 정도). 기울기가 크면 그 가중치가 오차에 관여하는 정도가 큰 것. 많이 수정해야 함. 
규제: 과적합을 막기 위해 모델에 제약을 거는 기법
드롭아웃: 은닉층의 뉴련을 일정 확률로 랜덤하게 OFF
조기종료: 과적합 되기 전에 학습 종료 
옵티마이저:머신러닝에서 손실 함수의 값이 최소가 되는 최적의 가중치를 찾기 위해 사용되는 알고리즘. 예: 경사하강법, Adam
 Adam: 관성 도입, 적응적 학습률(가중치마다 고유한 학습률 부여해서 최적의 학습 속도를 유지)

CNN모델
합성곱 레이어(convolution layer)
필터를 원본에서 이동시키면서 입력 값과 곱하고 합산하여 특징 맵(feature map)을 뽑아냄
필터가 6개면 활성화 맵도 6개

출력 해상도 = 입력 해상도 - 필터 해상도 +1
입출력 해상도를 유지하고 싶다면 1. 제로패딩 2. 가까이에 있는 값 채워넣기
가중치 w와 bias가 합성곱 레이어의 상수

모델 상수(파라미터)를 증가시키려면 ReLU라는 조건부 스위치를 끼워야 함

필터 시각화
선형 모델: 객체의 특징 반영 못함
FCN: 색깔, 위치 등 다양한 템플렛이 나옴
CNN: 계층별로 다른 이미지

수용 영역: CNN이 이미지를 처리하면서 한 번에 볼 수 있는 영역의 크기
네트워크가 깊어질 수록 수용영역도 넓어짐
conv : 레이어를 깊게 쌓는 구간

pooling:  feature map의 크기를 줄이는(다운샘플링) 연산
해상도를 작게 만듦. 출력을 줄여서 연산량을 줄이기
위치 변화 강건성(환경 변화에도 유지) : 앱력 내 객체 위치가 변해도 동일 출력 제공
몇 화소 이동되도 괜찮음
맥스 풀링: 정해진 커널 사이즈로 이미지를 나누어 각 영역 내 가장 큰 값을 선택하는 연산

ResNet은 잔차블록(블록 입력을 그대로 출력에 더해줌) 있음
배치 정규화 방식: 10개 레이어 이상을 학습 가능
레이어를 많이 넣었더니 에러가 더 높음 - 이를 해결하기 위한 잔차 블록
보틀넥 잔차 블록: 앞 뒤로 1x1짜리를 넣고 수용 영역을 가운데에 배치

stem 구조: 여러 개의 FC 대신 FC 1개만 남김. 해상도를 평균 내서 채널만 남김

RNN
순차적 데이터를 처리
이전 데이터를 hidden state에 저장해서 남기고, 새로운 데이터와 합쳐서 다음 단계에 전달
input chars: 원-핫 인코딩으로 input layer에 들어감
input layer: 0과 1로 된 벡터. 이후 은닉으로 변환
Hidden layer: 현재 입력에 이전 상태의 은닉을 합쳐 만든 내부 매모리
hidden state를 다음 단계로 전달
output layer: hidden state를 출력 벡터로 변환
target chars: 각 시점에서 예측해야 하는 정답. 이 정답과 output layer 확률을 비교한 오차로 가중치 업데이트

RNN 셀: 은닉층에서 활성화 함수를 통해 결과를 내보내는 역할
셀: 이전 값을 기억하는 메모리 역할 수행
시계열 의존성 : ht가 이전 상태 ht-1에 의존
순수 RNN : 선형 변환, 바이어스를 모델상수/비선형 (tanh 하이퍼볼릭 탄젠트) 함수 추가로 구성된 단순한 형태
